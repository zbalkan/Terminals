# Terminals 5.0.0 modernization roadmap

This is the **single status tracker** for the Terminals modernization program. The goal is to remove obsolete dependencies, preserve useful functionality and existing user data, improve responsiveness, and deliver a tested **5.0.0** release on the current **.NET Framework 4.8.1** baseline. Work is implemented on independent branches. **PR #6 is a permanent documentation-only planning branch: never merge it.** RDP PR #5 remains unchanged until modernization and cleanup are complete; do not rebase, update, or merge it during phases A–E.

**How to read the matrix:** **Done** means the recorded implementation or removal is on `master`; **Partial** means some work is merged but defined acceptance or further implementation remains; **Todo** means no completed implementation is established; **Deferred** means intentionally postponed. A completed implementation can still have release acceptance pending. The **Phase A–E** entries define the default execution order, subject to the explicit priority override below, and **Phase F** is deferred until modernization and cleanup finish. **Done** rows preserve completed implementation history, not acceptance certification. Rows are grouped by completed history, then A1–A6, B, C, D, E, and post-release Later items. Tasks in a phase may be performed in parallel where dependencies permit. IDs are optional references, not priorities.

Neither source inspection nor passing CI alone closes interactive acceptance.
