# Terminals 5.0.0 modernization roadmap

This is the **single status tracker** for the Terminals modernization program. The goal is to remove obsolete dependencies, preserve useful functionality and existing user data, improve responsiveness, and deliver a tested **5.0.0** release on the current **.NET Framework 4.8.1** baseline. Work is implemented on independent branches. **PR #6 is a permanent documentation-only planning branch: never merge it.** RDP PR #5 remains deferred.

**Snapshot:** November 19, 2026; `master` `7e8a771bceb9`. [DNS Lookup feature CI #44388969097](https://github.com/zbalkan/Terminals/actions/runs/44388969097) and [#44401686200](https://github.com/zbalkan/Terminals/actions/runs/44401686200) **passed** all three jobs (file/general tests, SQL/database tests and Inno Setup/portable ZIP validation) at the feature commit subsequently fast-forwarded to `master`. The preceding [WHOIS post-merge master CI #44317456788](https://github.com/zbalkan/Terminals/actions/runs/44317456788) **passed**. [DNS Lookup post-merge master CI #44403021573](https://github.com/zbalkan/Terminals/actions/runs/44403021573) **passed**. [Local network tools feature CI #44423405339](https://github.com/zbalkan/Terminals/actions/runs/44423405339) **passed** all three jobs on commit `7e8a771b`, now fast-forwarded to `master`. A new post-merge `master` CI run for this change is not yet verified. Automated CI does not establish interactive runtime, real DNS server behavior, historical data migration or licensing acceptance; FlaUI tests compile but do not execute in standard CI. VNC runtime functionality was previously user-confirmed without certifying every viewer/configuration.

**How to read the matrix:** **Done** means the recorded implementation or removal is on `master`; **Partial** means some work is merged but defined acceptance or further implementation remains; **Todo** means no completed implementation is established; **Deferred** means intentionally postponed. A completed implementation can still have release acceptance pending. The **Next** entries are execution order, **Later** entries follow modernization, and **Release** entries are 5.0.0 gates. IDs are optional references, not priorities.

The next implementation focus is Packet Capture and Port Scanner. Network Interfaces, Local Connections, Wake-on-LAN, Ping, Traceroute, NTP, WHOIS and DNS Lookup responsiveness implementations are merged with successful feature CI; their interactive acceptance remains open alongside WMI Explorer/Windows Services, Network Shares and FlaUI. PuTTY password handling, historical data migration, dependency provenance and distribution checks remain independently tracked. The remote protocol failure cache is passive: expiration alone **never initiates network traffic**. User-reported VNC runtime success does not certify all viewer configurations.
